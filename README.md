# Exercícios da aula do while 2

## Descrição do projeto Git
Projeto com três exercícios de JavaScript sobre o comando de repetição `while`. Em todos, o `while` controla se o programa continua ou encerra, e o `for` lê os números informados.

- **Exercício 1 :** soma de três números, repetida quantas vezes o usuário quiser.
- **Exercício 2 :** o usuário escolhe quantos números analisar e o programa mostra a soma e a média.
- **Exercício 3 :** soma, média, maior e menor número, com validação das entradas.

Os dados são digitados em janelas do navegador (`prompt` e `confirm`) e os resultados aparecem na página.

## Como executar ou visualizar
1. Clone o repositório:
   ```bash
   git clone https://github.com/Yoharya/algoritmo.git
   ```
2. Abra a pasta `exercicios-while`.
3. Dê um duplo clique em `index.html` para abri-lo no navegador.
4. Clique em um dos botões de exercício e responda às perguntas.
